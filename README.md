# QA Portfolio Project — Sauce Demo

## Overview

This repository contains an end-to-end QA portfolio project for Sauce Demo, a demo e-commerce application.

The project demonstrates my software testing approach through test strategy, manual test cases, bug reports, API testing, exploratory testing, and Playwright automation.

## Application Under Test

- Application: Sauce Demo
- URL: https://www.saucedemo.com/
- Domain: E-commerce
- Type: Web application

## Project Objectives

- Analyze the main user flows and identify testing risks.
- Design functional and negative test cases.
- Document reproducible defects with clear evidence.
- Test REST API endpoints using Postman.
- Automate high-value end-to-end scenarios with Playwright and TypeScript.

## Planned Scope

The project will cover:

- Login and authentication
- Product inventory
- Product sorting
- Shopping cart
- Checkout
- Order confirmation

## Repository Structure

- `Test-Strategy/` — Scope, risks, test approach, and coverage.
- `Test-Cases/` — Manual functional and negative test cases.
- `Exploratory-Testing/` — Exploratory session charters and findings.
- `Bug-Reports/` — Defect reports and supporting evidence.
- `API-Testing/` — API test cases and Postman collection.
- `Playwright/` — Automated UI tests using Playwright and TypeScript.
- `Evidence/` — Screenshots, reports, traces, and other evidence.
